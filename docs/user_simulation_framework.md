## 评估两大维度

### A类：功能正确性 (Functional Bugs)
- 注册/登录/退出流程是否完整
- 搜索功能是否正常返回结果
- 详情页数据是否正确显示
- CRUD操作（药箱/提醒）是否正常
- 安全检查是否拦截已知的配伍禁忌
- 体质自测问卷是否可完成
- 长辈模式是否正确切换
- 收藏功能是否正常
- 季节养生数据是否正确加载

### B类：产品差距 (Product Gaps)
按优先级分类：

**P0 (必须有)**:
- 语音输入（老年人核心需求）
- 孕妇安全标注（生命安全）
- 多家庭成员管理（家庭健康产品核心）
- 漏服提醒通知

**P1 (应该有)**:
- 中药功效分类筛选
- 方剂比较功能
- 健康指标记录（血压/血糖）
- PDF大字版导出
- 中西药交互数据库扩充
- 搜索历史/建议
- 通俗易懂版详情

**P2 (可以有)**:
- 学习模式（闪卡/方剂歌诀）
- 职业病专区
- 中医文化故事
- 视频内容
- 附近药店
- 价格参考
- 多账号协作

## 测试执行计划
1. 每个spec文件独立执行
2. 收集所有PASS/FAIL结果
3. 分析失败原因：是bug还是预期行为
4. 汇总所有PRODUCT GAP注释
5. 专家讨论优先级排序
6. 实现高优先级修复
